01 · Start with a research question

Does delivery change observable agent work?

V2 holds the task, model, tools, context, budget, and evaluator constant. A0 adds no behavior instruction; A1, A2, and A3 carry semantically equivalent instructions through different delivery mechanisms.

All four arms solved all five tasks in all three trials. That is a correctness result, not evidence that one mechanism universally wins.

08 · Methodology

Freeze the comparison. Observe the boundary.

01

Freeze

Task specs, visible fixtures, registry, and scripts are fixed within the comparison.

02

Isolate

Each candidate starts fresh with visible task context; evaluator implementation stays outside it.

03

Evaluate

Acceptance, regressions, scope, reliability, efficiency, and safety are scored from observable evidence.

04

Calibrate

Missing or unverifiable evidence is UNKNOWN—not PASS.

Why a hidden grader?

It protects evaluation from being solved by copying an answer. This site explains the concept and boundary without exposing evaluator content.

09 · Learn by doing

Practical habits for better agent work

Use protocols as checklists for observable behavior, not incantations. Start with sufficient context, trace the responsible path, make a scoped change, then rerun the real path and regressions.

02

Separate outcome from efficiency

03

Repeat before ranking

One sample can describe; repeated trials help reveal reliability and variance.

Glossary

Arm
One delivery mechanism being compared.
Cell
One task × arm × trial combination.
Protocol
A named behavior contract with a purpose and observable signals.
Descriptive evidence
A report of what this sample did, without a universal claim.
Hidden grader
An evaluator-owned test that checks the result without revealing its answer.
UNKNOWN
The status for missing or unverifiable evidence; it is not a pass.
